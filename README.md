# Fleet Management Backend — Prototype (Pydantic)

This branch contains the prototype backend built using Pydantic.  
It was used to explore domain modeling, validation rules, update flows,  
and service/repository architecture before migrating to Django.

Key features:
- Pydantic domain models with validation
- Service layer for update logic
- Repository layer for CRUD operations
- Early architecture experiments
- Foundation for the final Django backend

This branch is intentionally preserved as a reference for the final implementation.
